# human/ — protected reference versions

Files in this directory are **human-authored reference versions** of the internship
scripts, kept as an untouched snapshot of Christian's own edits.

**Claude must not edit anything under `human/`.** When a script here and its working
counterpart under `internship_tasks/<level>/` disagree, this copy is the authority on
*style and intent*; the working copy is what Claude propagates the style into.

Workflow: Christian edits a script → it is copied here as the frozen reference →
Claude brings the working copies into line with it. To refresh a reference after new
human edits, re-copy the working file over the one here.
